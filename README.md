# file_heandling
A beginner-friendly Python project demonstrating file creation, reading, writing, updating, and basic file management.
File Handling App is a Python-based application that demonstrates file handling through an interactive user interface. The main.py file contains the backend logic for creating, reading, writing, updating, and managing files, while the app.py file provides the application interface through which users can interact with these functions.

The project connects the backend file-handling operations with a simple frontend, making file management easier to understand and use.
